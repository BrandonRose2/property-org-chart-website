# Apartment Corp Properties – Org Chart: Design Ideas

## Approach 1: Industrial Steel Command Center
<response>
<text>
**Design Movement:** Industrial Brutalism meets Digital Command Center

**Core Principles:**
- Textured steel-grey backgrounds with subtle noise/grain
- Tactile 3D metallic buttons with press-in hover animations
- High-contrast typography with monospace accents for data
- Structured hierarchy with visible grid lines

**Color Philosophy:** Steel greys (#1a1f2e, #2a3040) as base, with four metallic accent gradients — orange for Section 8/HUD, blue for LIHTC, yellow for Layered HUD/LIHTC, and dark steel for conventional. Colors evoke industrial authority and institutional weight.

**Layout Paradigm:** Full-width command dashboard with a sticky header stats bar, horizontal region accordion panels, and a three-column property card grid per region.

**Signature Elements:**
- Embossed/debossed card surfaces with inset shadows
- Metallic gradient buttons with shine effect
- Steel-riveted panel borders

**Interaction Philosophy:** Press-in button feedback, region collapse/expand, hover glow on property cards

**Animation:** Staggered cascade entrance (30ms per card), smooth region expand/collapse, button press translateY(2px)

**Typography System:** Rajdhani (bold display) + Inter (body) — industrial geometric sans
</text>

## Approach 2: Tactical Dark Atlas
<response>
<text>
**Design Movement:** Military Cartography meets Modern SaaS Dark Theme

**Core Principles:**
- Deep navy/charcoal backgrounds with subtle topographic texture
- Crisp white typography with color-coded region badges
- Map-integrated layout with property pins
- Data-dense but breathable card layout

**Color Philosophy:** Deep navy (#0d1117) base, with region colors as accent — each region gets a distinct hue (teal R1, amber R2, emerald R3, rose R4, violet R5). Property type badges use the original orange/blue/yellow scheme.

**Layout Paradigm:** Split-screen: left sidebar with region navigation tree, right main area with filterable property grid. Sticky filter bar at top.

**Signature Elements:**
- Glowing region color borders on cards
- Subtle grid/crosshatch background texture
- Pill-shaped region badges with glow

**Interaction Philosophy:** Sidebar region selection highlights all matching cards, smooth filter transitions

**Animation:** Fade-in with slight upward drift (opacity 0→1, translateY 8px→0), 200ms ease-out

**Typography System:** Space Grotesk (headers) + DM Sans (body) — technical precision
</text>

## Approach 3: Refined Corporate Directory
<response>
<text>
**Design Movement:** Premium Corporate Directory meets Editorial Design

**Core Principles:**
- Clean off-white/light grey backgrounds with strong typographic hierarchy
- Color-coded property type system as primary visual language
- Generous whitespace with structured information density
- Professional yet approachable

**Color Philosophy:** Warm off-white (#f8f7f4) base, charcoal (#1c1c1e) text, with the three property type colors (orange #d88840, blue #4070b8, yellow #c8a840) as the primary accent system. Region headers use a dark charcoal band.

**Layout Paradigm:** Full-width with collapsible region sections, each containing a responsive card grid. Sticky top navigation with search and filters.

**Signature Elements:**
- Left-border color accent on each card indicating property type
- Region summary stats in a horizontal band
- Clean table/card hybrid for property listings

**Interaction Philosophy:** Smooth filter animations, hover card elevation, click-to-expand details

**Animation:** Cards slide in from bottom (translateY 16px→0), 150ms stagger, ease-out

**Typography System:** Playfair Display (region headers) + Outfit (body/cards) — editorial authority
</text>

</response>

**Selected Approach: Approach 1 — Industrial Steel Command Center**

This matches the existing live site's aesthetic and the original PDF's intent. The metallic 3D buttons, steel-grey palette, and color-coded property types (orange/blue/yellow/steel) are the defining visual language of the Apartment Corp brand.
